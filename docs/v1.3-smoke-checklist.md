## 1. Import — Unknown Focal Length Prompt

Use `~/Downloads/Ledger v1.3 Smoke Test/Unknown Focal Length/` (CSV + JPEGs — one frame at a
registered focal length as a control, several frames split across two unregistered focal
lengths).

**1.1** Import the CSV as an EOS-1V source with Lens Model enabled. A single alert titled **"No
Registered Lens Matches"** appears — not one popup per file.
**1.2** The alert body correctly names both unmatched focal lengths and the total frame count
(e.g. "Ledger couldn't find a registered lens for N frames at Xmm and Ymm.").
**1.3** **Manage Lenses…** is the default button (highlighted / triggered by Return).
**1.4** Click **Manage Lenses…** — the lens registry sheet opens. Add a lens covering one of the
two unmatched focal lengths, click **Done**. The import automatically retries — no need to click
Import again.
**1.5** If a lens was registered for only one of the two focal lengths, the alert reappears for
the remaining one.
**1.6** Click **Continue Without Lens Tags** — the import proceeds; those frames stage with every
field except Lens Model (field is omitted, not written blank).
**1.7** Re-run the same import from scratch (new import sheet). The previously-acknowledged focal
length is **not** remembered — it prompts again. ("Remember nothing permanently" — the decision
only applies within one import.)
**1.8** Click **Cancel Import** — backs out to the main import sheet without staging anything for
the affected rows.
**1.9** The one frame at the registered control focal length imports its lens tag correctly
throughout, regardless of which button is chosen for the others.
